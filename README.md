MULTIPLY FUNCTION:
The multiply(a,b) function computes the product of a and b using the variables given above. It could break if the user tried to print the final product by calling 3 variables since the function is programmed to only handle 2.

SUBTRACT FUNCTION
The subtract function takes 2 arguments and returns the difference, subtracting the second from the first.
The function will return an error when calling it with less or more than 2 arguments.

SQUARE FUNCTION:
The square function takes the multiply_ab function and uses it on a single value. It can only take a single number at a time.
